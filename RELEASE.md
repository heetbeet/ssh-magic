SSH Magic provides temporary SSH assistance for Windows x64 and Linux x64. Run the short root bootstrap, read back the code, and have the operator run it with `connect CODE`. Commands, file transfers, native SSH configuration, explicit admin access, and session revocation are included.

The host remains a foreground process. Ctrl+C, terminal closure, `close help`, or the two-hour deadline ends access. No SSH service, account, router rule, firewall rule, startup task, or persistent execution-policy change is installed. Downloads remain cached for subsequent use. Optional `install` adds `ssh-magic` to your user PATH without starting access. `remove` uninstalls the command and cache. ZIP and tar.gz bundles install offline.

Pairing uses Magic Wormhole over TLS. Iroh attempts a direct connection and falls back to a public relay. Public relay availability is outside this project's control. These binaries are unsigned and may trigger platform reputation warnings.
